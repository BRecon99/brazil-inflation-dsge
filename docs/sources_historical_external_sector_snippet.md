## Historical Brazilian external-sector sources

- Doellinger, Carlos von; Faria, Hugo Barros de Castro; Cavalcanti, Leonardo Caserta (1974), *A política brasileira de comércio exterior e seus efeitos: 1967/73*, IPEA/INPES, Relatório de Pesquisa n. 22. Table VI.2 is the primary source for import composition by use in 1967-1972.
- Serra, José (1982), “Ciclos e mudanças estruturais na economia brasileira do após-guerra,” *Revista de Economia Política*, 2(2), 145-183. Table 13 is the primary Brazil-specific annual validation source for import prices by category.
- Pereira, Francisco das Chagas (1978), *Dossiê sobre Energia*, IPEA/IPLAN. The import-structure table for 1960-1977 is retained as a secondary historical cross-check; category changes and published inconsistencies are flagged rather than corrected.
