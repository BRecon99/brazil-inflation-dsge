# Structural openness parameters: alpha, mu and lambda_s

## Baseline sample
1968-1972.

## alpha
`alpha_t = cf_y_t / c_y_t`
Baseline alpha = 0.015130.

## mu
`mu_t = z_y_t / (labor_share_t + z_y_t)`
Baseline mu = 0.068279.
Employee-compensation-only robustness mu = 0.091985.

## lambda_s
`lambda_s = mu + (1-mu)*alpha`
Baseline lambda_s = 0.082376.

GDP is reused from Script 06 rather than re-extracted in Script 07. This avoids ambiguity from multiple GDP-labelled rows in the historical IBGE workbook.
