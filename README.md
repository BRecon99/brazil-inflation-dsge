# Brazil 1964–1980 Inflation DSGE

Reproducible research repository for the Brazil 1964–1980 small-open-economy DSGE project.

## Current status

- Structural baseline: 26-equation Dynare model.
- Household foreign bond: excluded.
- First reproducible parameter estimate: `rhoiw` (`rho_i*`), persistence of the world interest rate.
- Raw first dataset: FRED `TB3MS`.
- Recommended first-stage estimate:
  - `rhoiw = 0.862905`
  - standard error = `0.080906`
  - shock SD = `0.001298`
  - sample = `1964Q1-1972Q4`

These estimates are generated by code. Do not manually edit generated result files.

## Repository map

```text
data/raw/           Original files. NEVER edit manually.

R/                  Data cleaning, calibration, and first-stage estimation.
dynare/baseline/    Frozen successfully running structural model.
dynare/estimation/  Future measurement equations and structural estimation.
dynare/counterfactuals/ Future counterfactual model files.

docs/                Parameter registry, data dictionary, research decisions.
output/estimates/    Machine-generated parameter estimates.
output/figures/      Machine-generated figures.

```

## Rule 1: never edit raw data

The reproducibility chain is:

```text
raw data -> R scripts -> processed data -> estimates -> Dynare -> paper results
```

If a transformation changes, change the R script and rerun it. Never fix a processed number manually in Excel.

## Parameter workflow

Every parameter must have one row in `docs/parameter_registry.csv`.

### Estimated
The value comes from data. Record:
- equation;
- estimator;
- sample;
- exact raw data;
- transformation;
- estimate;
- standard error or posterior interval;
- shock SD if relevant;
- robustness checks.

### Calibrated
The value is fixed before structural estimation from:
- a historical average;
- an accounting ratio;
- micro evidence; or
- literature.

Record the exact calculation and citation.

### Fixed / derived
The value is forced by algebra once primitive parameters are known.

Examples:
- `lambda_s = mu + (1-mu)*alpha`
- `kappa = ((1-theta)*(1-beta*theta))/theta`
- `invPi = 1/Pi_ss`

Do not estimate these independently.

## Suggested order

1. `rhoiw` — DONE as first-stage example.
2. `Pi_ss` — calibrate from Brazilian pre-1973 inflation.
3. `invPi` — derive mechanically from `Pi_ss`.
4. `rhoF` — estimate from foreign/import price data.
5. `rhoystar` — estimate from foreign activity data.
6. Accounting and steady-state calibrations.
7. Measurement equations.
8. Structural Dynare estimation of key parameters.

## R package reproducibility

The first script uses base R only.

When packages are introduced, initialize `renv` once in the project:

```r
install.packages("renv")
renv::init()
```

After adding or changing project packages and confirming the code works:

```r
renv::snapshot()
```

A collaborator can later restore the recorded environment with:

```r
renv::restore()
```

Official renv documentation:
https://rstudio.github.io/renv/
