# Structural estimation model

Do not edit the frozen file in `../baseline/`.

This folder will contain a copy of the baseline model extended with:
1. observables;
2. measurement equations;
3. `estimated_params`;
4. priors / bounds;
5. `estimation(...)`;
6. identification diagnostics.

Do not create the full structural estimation file until the data dictionary and
basic calibration/first-stage estimates are substantially populated.
